Choose what you use ​

Settings → Capabilities (/settings/capabilities, administrators only) is where an instance says what else it does once results arrive. It opens on one coarse question, What do you want Piwi for?, with See why tests fail always on and three opt-out groups: Triage as a team (notifications, quarantine, pull-request feedback, issue tracking), Fix faster (locator healing, auto-heal), and Let agents in (AI diagnosis, the assistant). Below it, a ladder lists every optional capability grouped by state: Active (evidence has arrived), Available (configured but not used yet), Not set up, and a folded Declined group. The page ends with Off until turned on: Run on my machine and Pass reuse stay off until an administrator turns them on.

Declining a capability ​

Not every team uses every capability. Any optional one can be declined so the dashboard stops showing it everywhere: the evidence tabs, empty panels, settings page, sidebar entry, project actions and MCP tools it owns all go, rather than lingering half-visible. Decline instance-wide from the ladder (Not for this instance) or the presets, or per project from the Capabilities section of the project's Settings tab and the places the capability appears (for example the execution page's evidence footer, Not for this project). A project override can also enable a capability the instance declined.

Declining instance-wide is for administrators, and per project for the project's Project admin role. It is never final: each declined capability keeps a Reconsider link on the ladder that clears the decision, and because data always wins, a declined capability that starts receiving data reads as active again with the stored decision shown next to it. Why a card is empty says how this reads on the execution page.

Why a card is empty ​

On the execution page, a tab that needs the capture fixtures appears only when it holds data or the fixtures ran and found nothing; otherwise one footer line names the missing tabs. An empty card says which case applies: captured, nothing happened, not applicable (backend logs need a backend integration), or declined for this project (Declining a capability). The AI diagnosis's Data coverage block uses the same words.
