Browser extension ​

NeedsBrowser extension

Piwi Picker is a Chrome, Edge and Firefox extension that picks ranked, stable Playwright locators from the page you are looking at, scored by the same engine the dashboard uses, and records a multi-page flow into a runnable TypeScript spec. It works standalone and sends nothing by default; connecting it to a Piwi instance adds what needs your project's history.

What it does ​

Every tool below runs on the live page, from the toolbar popup. The last three need a connection to a Piwi instance; the others never reach it.

ToolFor
Pick an elementa ranked locator for one element, re-checked against the page
Multi-pickthe shared pattern of a list's rows or cards
Lint overlaythe elements that would make bad locator targets
Assertion suggesterexpect(...) lines for an element
Copy context for agentone block about an element for a coding agent
Record actionsa runnable spec from clicks and fills across pages
Report a buga failing test and a report of a bug you reproduce
Developer toolsin DevTools: the selected element's locators, the locator console, the session, mocks, viewports
Runs windowpause, step and resume the tests your editor runs, and watch a headless one live
Matching functionsa recording that calls your own functions
Test functionswhich of your functions work on this page
Tested elementswhich elements of this page your tests reach

Where it is ​

Install Piwi Picker from the Chrome Web Store ↗ for Chrome or Edge 118 or later (in Edge, click Allow on the Allow extensions from other stores banner once, then Get), or from Firefox Add-ons ↗ for Firefox 140 or later.

Every tool in the popup has a tile with a line under its name saying what it is for, and a key (1 records, 2 picks, B reports a bug). One tool runs at a time and Esc cancels it; recording runs until its own Stop. The tools that need no pick on the page are in the browser's DevTools: Developer tools.

Picking also has a shortcut, Ctrl+Shift+E by default (Cmd+Shift+E on macOS); the popup footer shows the key bound.

Test functions against this page ​

Test functions in the popup scores every function of the active project's catalog against the page: Ready to use here (every step finds one element), Partly found here, or Not on this page.

Tested elements ​

With a connection, Tested elements outlines every element of the page a test of the active project reaches, lists those tests, and marks the buttons, links and fields no test reaches.

Runs from the editor ​

With Piwi Picker paired with VS Code or a JetBrains IDE, the popup's Runs tile, under More tools, opens the Runs window: the tests your editor runs, paused, stepped and resumed from a window beside them, code written from a stop, and a headless test's page watched live, clicked and typed on, and picked on.

Languages ​

Piwi Picker speaks English, French, German, Spanish and Brazilian Portuguese, following the browser unless Language, in the settings, picks another. German, Spanish and Portuguese are unreviewed drafts: suggest a correction. A bug report is written in the extension's language; locators, test ids and specs never are.

Sites Piwi Picker may run on ​

Recording, replaying, Save login and the DevTools pane each ask for the site you are on the first time they need it, and the access stays until you take it back. Settings → Sites Piwi Picker may run on lists every site allowed with a Revoke button; Piwi Picker then runs there only when you click its icon. A site a recording or a replay runs on keeps its access until it ends, and your instance's address, the desktop app's and the editor's are given back by Disconnect and Unpair.

Connecting to a Piwi instance ​

Optional and off by default. In the settings, type your instance's address and click Connect, then Allow in the tab that opens: Piwi Picker receives its own API key. Which project applies on a page comes from URL patterns kept on the instance and from any you keep in this browser; the popup's Active project select overrides both for the session. See Extension connection.

A recording is never sent to your instance, and a bug report only from its preview.

Limits ​

  • One frame at a time. The picker and the recorder see the top-level document, not iframes.
  • Open shadow roots only. The picker reaches inside open shadow roots; a closed one is out of reach, and a pick there picks its host element. The recorder records the fields of open shadow roots, and from a closed one only the keys of a password field (Enter, Escape, the arrows).
  • Recording covers one origin. On another site it stops capturing: stop and review, or start again there.
  • No ARIA snapshot from a plain pick. toMatchAriaSnapshot() code comes from Assert a region, at a stopped test in the Runs window.
