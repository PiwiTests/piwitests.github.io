Command line ​

NeedsReporter

The @piwitests/reporter package installs a command, piwi, for what happens around a test run. Run it through the package name, npx @piwitests/reporter <command>, or as npx piwi <command> once the reporter is a dependency of the project. This page says which command serves which moment; every flag, and how a command finds the dashboard and its API key, is on the Piwi CLI reference.

Setting up ​

  • init wires a Playwright project up to a dashboard: the reporter, the capture fixtures, a .env and the agent skills.
  • skills installs or updates the agent skills in a project init did not set up.
  • mcp serves the runs of this machine's editors and desktop app to a coding agent (Run control for agents).

In CI ​

  • gate fails a job on the dashboard's analysis of the run: the CI merge gate.
  • rerun runs the tests a re-run in CI asked for, in a GitLab, Bitbucket or Jenkins job.
  • report prints a quality report, for a scheduler to post.
  • coverage uploads another tool's coverage of a commit, for combined coverage.

Choosing the tests ​

  • select and run resolve a saved test selection, or the tests a diff reaches (Impact from a diff), and print or run them.
  • plan plans a run that reuses the passes whose code has not changed (Reuse forecast), an experimental capability.
  • probe runs the dashboard's probe plan.

Chasing a flaky test ​

  • flake makes a flaky test fail on demand under its suspects' conditions, then verifies the fix (Flake Lab).

Writing and fixing a test ​

  • codegen turns a Piwi Picker recording into a spec (Record actions).
  • bug writes a bug report's failing test into the project and runs it.
  • preflight lists the test locators your change breaks, and fixes them (Locator preflight).
  • ai manages the committed artifacts of AI steps.
