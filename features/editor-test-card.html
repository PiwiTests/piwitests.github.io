Test card ​

NeedsEditor extension

A test's card answers "my bug or a flake?" without leaving the editor. In VS Code it is the test's hover on its test(…) line; in a JetBrains IDE, a click on the test's result icon opens it.

What it shows ​

  • The strip: the test's latest runs, oldest on the left, as the dashboard's test row draws them: ✓ passed, ✗ failed, ◐ flaky (it passed on a retry), ○ skipped. A run is one mark, whatever its retries, repetitions and projects: failed when one of them ended failed, flaky when one passed on a retry. Each mark links to its run, and its tooltip names the run, the outcome and how long the test took.
  • How far back: twenty runs at most, read from the test's last 50 attempts, so a test run in three projects shows about sixteen, and one run with --repeat-each fewer still. The dashboard's test page holds its whole history.
  • How they went: Passed 17 of the last 20 runs · 2 flaky · median 1.4 s, skipped runs left out.
  • The last failure: the run it failed in, how long ago, and the first line of its error.
  • Its owner, tags and quarantine: the owner its piwi:owner annotation names, its Playwright tags, and, while it is quarantined, for how long and how many passes it has toward release.

Under the card, Run runs the test, Open in dashboard opens its page, and More… opens the test's actions: Runs from the editor lists them.

Where it comes from ​

The editor reads the test's history from the instance as the card opens, and keeps it for 30 seconds. It waits for it one and a half seconds at most: past that, the hover shows the test's result in one line, and a click in a JetBrains IDE opens the test's actions. A test the instance does not know yet has no card.
