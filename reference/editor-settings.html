Editor settings ​

Both editors group their options as this page does: VS Code in its settings editor (search piwi.), and Settings → Tools → Piwi in a JetBrains IDE, whose help button and Documentation links open this page. A row that names one editor is that editor's alone; the JetBrains page has no Advanced group, and opens with the connection in use and a group for the desktop app.

Each option is one of three kinds:

  • The team's: one value for everyone on the project. VS Code reads it from the user or the workspace settings, which a repository may commit (.vscode/settings.json); a JetBrains IDE keeps it in .idea/piwi.xml, which the team can share.
  • Yours, which a project may set: your choice, which a workspace's settings can set for that project. A JetBrains IDE keeps it for you in the project's .idea/workspace.xml.
  • Yours: the same in every project. VS Code reads it from the user settings alone, so a repository cannot change it; a JetBrains IDE keeps it in the IDE's own settings (options/piwi.xml).

In Rider, a project's .idea files sit under .idea/.idea.<Name>/.idea/, as the settings page says.
