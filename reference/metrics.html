Metrics ​

The metric catalog: every number the analytics widgets, the quality reports, the MCP tools and the metrics export show, so a number means the same thing wherever it appears. Days are UTC.

History says how far back a metric reaches. Any period: it is read from the daily rollups, which keep their numbers when retention deletes old runs. Stored rows: it is read from the runs, clusters or gaps still stored, so a metric about test identities reaches back only as far as retention keeps runs.
