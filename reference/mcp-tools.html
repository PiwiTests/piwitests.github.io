MCP tools ​

The MCP server serves 86 tools. Each belongs to one module, the groups the Setup page asks about, and ?modules= on the MCP URL narrows the list to some of them. A tool with a capability leaves tools/list and tools/call when an administrator declines that capability for the instance; a tool without one is always served.

Each entry here is the summary line of the description the server sends to the agent. The MCP server page of the dashboard (/mcp) lists the same catalog with each tool's whole description and parameters, and leaves out the tools of declined capabilities.
