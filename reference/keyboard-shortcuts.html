Keyboard shortcuts ​

The dashboard's shortcuts, by where they work. The letter keys never fire while you type in a field.

Anywhere ​

KeysAction
Ctrl + K (⌘ + K on macOS)Open the command palette: go to a page, search projects, runs and tests, start a guide, or ask the assistant
Ctrl + I (⌘ + I on macOS)Open the assistant's panel; pressed again, put the cursor in its question field, then close it
g then hGo to Home
g then pGo to Projects
g then aGo to Analytics
g then sGo to Settings

Desktop app ​

In the desktop app's dashboard window. On macOS the app menu holds the first four with ⌘, beside the docs, and zoom takes ⌘ too; Windows and Linux use Ctrl, outside a field you type in.

KeysAction
Ctrl + ,Open Settings
Ctrl + OPick Playwright archives or bug reports to import
Ctrl + [Go back
Ctrl + ]Go forward
Ctrl + + / - / 0Zoom in, out, back to 100%

Piwi Picker's Runs window ​

In Piwi Picker's Runs window, for the stopped test whose row holds the focus, else the only stopped test shown: a run's worker tabs show one worker at a time. Step and Finish wait for a stop that is no failure.

KeysAction
F8 or F5Resume
F10Step
Shift + F11Finish

While Interact is on at a watched stop, the view takes your keys: characters are typed, named keys (Enter, the arrows, Backspace, Delete, Home, End) pressed, with Shift, and Ctrl (⌘ on macOS) with A, Z, Y, Enter and the editing keys. The browser's other shortcuts, the function keys and Esc stay the window's: Esc turns Interact off, gives the stop back and moves the focus to Interact. While a pick or a check runs on the page, Esc goes to the page instead, as its own key. Tab moves the focus on past the view, unless you clicked into it: then Tab and Shift+Tab go to the page too, until Esc turns Interact off. Characters an input method composes (Chinese, Japanese, Korean) do not reach the page; paste them instead. The desktop app's Local runs tray takes the same keys. On a run's worker tabs, the arrow keys, Home and End move between the workers.

The run shortcut ​

Piwi Picker's run shortcut works from any window. It resumes the stopped tests, else pauses every run, but a run nobody attends; Piwi Picker's toolbar icon shows what it did for a moment. It has no key until you set one: Set a shortcut, in the Runs window, opens the browser's shortcuts page, where you give it a key and, in Chrome and Edge, the Global scope. In Firefox, it works while Firefox has the focus.

Assistant panel ​

In the assistant's question field:

KeysAction
EnterAsk; Shift + Enter starts a new line
↑On the first line, bring back your previous question, from any of your conversations
↓On the last line, go back toward what you were typing
→In the empty field, take the question it shows greyed: the one the last answer suggests, or the page's
EscStop the answer being written

Failure inbox ​

On the failure inbox, the keys act on the selected row. The triage actions need the Maintainer role or above on the project.

KeysAction
j / kSelect the next / previous row
Shift + j / kExtend the selection down / up
xAdd the row to the selection, for the bulk bar
EscClear the selection
oOpen the cluster
rResolve
iIgnore
qQuarantine the cluster's tests
aAssign
sSnooze
lLink a known issue
cCreate an issue in the connected tracker, when the cluster has none

Test lists ​

On a run's and a project's Tests tab (test search):

KeysAction
Ctrl + F (⌘ + F on macOS)Focus the search box; pressed again there, open the browser's find
↓ / ↑Move through the search suggestions
Enter / TabTake the highlighted suggestion
EscClose the suggestions

Screenshot viewer ​

KeysAction
← / →Previous / next image
EscZoom out, then close

Element picker ​

When you pick a replacement locator on a captured page:

KeysAction
↑Select the parent of the highlighted element
↓Go back down to the child
EscSkip picking, without choosing an element

Permission grid ​

On the permission grid, the arrow keys move between cells, and Home / End jump to the first / last column of the row. Space or Enter opens the focused cell's role menu, and Esc closes it.
