Editor commands ​

Every command the two editors offer, by what it acts on. VS Code lists them in the command palette under Piwi:; a JetBrains IDE lists them under Tools → Piwi, a run's in its Run control submenu, and in Find Action, says caret for cursor and project for window, and shows a toggle's state with a check mark. A row that names one editor is that editor's alone. Some commands have a shortcut in both editors (Keys); a run's controls take the debugger's keys (The controls).

Keys ​

Ctrl+Shift+Alt with a letter, Cmd for Ctrl on macOS. Record here… and Run the test at the cursor act in an editor of a JavaScript or TypeScript file, the others there and in Piwi's views (the Piwi tool window in a JetBrains IDE), and nowhere else. A JetBrains keymap where that chord is another action's in those places takes the letter of its row, as do the keymaps descending from it. Settings → Keymap shows $default as Windows, Mac OS X 10.5+ as macOS, Mac OS X as IntelliJ IDEA Classic, and Default for XWin, Default for GNOME and Default for KDE as XWin, GNOME and KDE; it drops OSX and (Mac OS X) from the other names, adding (macOS) on Windows and Linux.

Where the run controls are ​

  • In VS Code: the Piwi item's menu while they apply, after Go to the stopped line; the command palette; the editor title, Pause or Resume, Step, Finish and Stop (on a run this window started) in the debug toolbar's order, the others under …; and, while a test is stopped, in the editor's context menu, right after its Go to entries, and on its worker's page (Resume, Step, Finish and Write code…).
  • In a JetBrains IDE: Tools → Piwi → Run control and the Run menu, enabled while they apply; the toolbar of the run's Run tab, acting on that run; the status bar item's menu; and, while a test is stopped, first in the editor's context menu, and on its worker's tab (Resume, Step, Finish and Write code…).

A run is named after what it runs (checkout.spec.ts:12, a.spec.ts and 2 more, the title it greps, ×3 after a Verify ×3, a Flake Lab line's command), in its terminal or Run tab and wherever you pick it, where it also has its number on the instance once it has one (Run #78 · checkout.spec.ts:12). Two runs of one name show their refs.
