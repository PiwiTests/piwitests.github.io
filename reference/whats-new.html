What's new ​

The features that landed in each release, newest first — the answer to "what changed since I last upgraded, and is any of it worth reading about". It is generated from the project changelog, which also holds the bug fixes and the full commit history.

Piwi is pre-1.0: minor releases can carry breaking changes and the database schema moves with them, so read Upgrading before you bump a tag.
